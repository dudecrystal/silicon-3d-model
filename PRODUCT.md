# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User specified React, Vite, TypeScript, Three.js, React Three Fiber, Drei, Tailwind CSS and Motion. Deploy to Vercel Hobby with GitHub source.

## Users
Ranveer Singh, Honors Chemistry classmates and teacher, exploring silicon's three naturally stable isotopes on school laptops and phones.

## Product Purpose
Represent silicon for Part II of an Honors Chemistry Element Project through three interactive Bohr-style atomic models.

## Capabilities and Constraints
Single page; Si-28/29/30, 14 protons and electrons with 14/15/16 neutrons; shells 2/8/4. Orbit, zoom, particle picking, camera focus and reset. Geometry generated locally, no backend, APIs, paid tools or large textures. Under 100,000 triangles. Initial loading skeleton and explicit WebGL fallback. Exact supplied title, description and disclaimer.

## Accessibility & Inclusion
Keyboard controls, visible focus, touch orbit/zoom, reduced motion, descriptive text and color-independent particle labels. School Chromebook performance matters.

## Brand Commitments
User supplied dark scientific palette, coral/purple/cyan particles, centered header, circular isotope navigation and compact information. No extra pages, dashboard cards, decorative glow or unrelated educational features.
